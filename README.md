# Hendy Dịch Vụ Mạng — aiogram v3

Repository khởi tạo chính thức cho Hendy Dịch Vụ Mạng Telegram Bot.

Mã nguồn được bổ sung theo kiến trúc aiogram v3, asyncio, HomeProxy Hub API adapter, JSON store, Render Web Service và GitHub Actions CI.

Xem hướng dẫn cài đặt, cấu hình môi trường, kiểm thử và triển khai trong README hoàn chỉnh sau khi đồng bộ mã nguồn.
